Как подключить агента

Запустите scripts/install-mcp.ps1 из папки проекта для регистрации в Codex. Для других клиентов добавьте stdio-сервер с командой dist/openconnectmulti-mcp.exe (полный путь).

Инструменты: vpn_status, vpn_list_profiles, vpn_switch_profile, vpn_disconnect, vpn_open_app. Подробности — docs/MCP.md.
