# Режим «Мульти» (Windows, предварительная версия)

Несколько профилей работают одновременно, каждый в собственном процессе
OpenConnect и интерфейсе `OCM-…`. Один профиль можно назначить для интернета,
остальные добавляют рабочие маршруты, полученные от своих серверов.

## Первый запуск

1. В старой версии отключите VPN и полностью закройте приложение. Если старая
   версия остаётся запущенной, новый EXE откроет её окно вместо новой версии.
2. Распакуйте весь архив в отдельную папку. Запустите `openconnectmulti.exe`.
   Введите PIN в окне приложения. Существующие профили доступны из прежнего
   хранилища; переносить или раскрывать пароли не требуется.
3. Выберите **Мульти**, в **Интернет через** выберите **xRocketVPN**,
   нажмите **Применить**. Назначение сохраняется, но само по себе VPN не включает.
4. Отметьте **Выбрать все** или нужные профили и нажмите
   **Подключить выбранные**.
5. Проверьте интернет и по одному известному рабочему ресурсу за каждым VPN.
   Статус **Настроен** подтверждает выполнение настройки интерфейса и маршрутов,
   но не доступность конкретного сайта, SSH-сервера или базы данных.

Для Plush/Fiscal не требуется SOCKS/HTTP-порт, если они, как прежде, просто
предоставляют доступ к рабочим сетям без смены интернет-IP. Это раздельная
маршрутизация. Программа не создаёт SOCKS/HTTP-прокси.

## Маршруты и DNS

- По умолчанию используются IPv4 split-include сети, полученные от VPN-сервера.
  Маршруты `/0` и пары `/1` может устанавливать только выбранный VPN для интернета.
- Если сервер не отдаёт рабочие сети, добавьте их в **Изменить → Дополнительные
  параметры → Рабочие IPv4-сети**. Используйте реальные CIDR сети, по одной на
  строку. Не угадывайте диапазоны: их можно узнать из журнала прежнего подключения
  или у администратора сети.
- Домены из split-DNS/default-domain сервера и дополнительные домены профиля
  получают отдельные правила Windows NRPT с DNS данного VPN. VPN для интернета
  получает DNS-правило по умолчанию; более конкретные рабочие домены используют
  DNS своих профилей. Если сервер не сообщает домены, укажите их вручную.
- Пересекающиеся рабочие диапазоны, одинаковые DNS-серверы за разными VPN и
  одинаковые DNS-области между профилями считаются конфликтом. Проблемное
  подключение останавливается, остальные сохраняются. Для одинаковых IP с разным
  назначением потребуется изоляция или отдельные прокси — эта версия их не вводит.
- Публичные адреса VPN-серверов закрепляются за исходным интернет-шлюзом при
  настройке туннеля. Исключения интернет-профиля не должны перехватывать рабочие
  сети других профилей.
- Эта версия управляет **IPv4**. IPv6 не запрашивается у VPN-серверов и продолжает
  работать через обычное подключение Windows. Это не режим полного сокрытия IP.

## Отключение и восстановление

Кнопка **Отключить** в профиле останавливает только его процесс, удаляет его
маршруты и правила DNS. **Отключить все** останавливает все профили. Смена режима
или VPN для интернета требует предварительного отключения всех подключений.

Сетевой журнал восстановления находится в `%APPDATA%\OpenConnectMulti\network-runtime`.
Он содержит сетевые настройки и идентификаторы процессов, без паролей. После
аварийного завершения при следующем подключении в «Мульти» клиент останавливает
оставшиеся свои процессы (проверяя PID и время создания) и убирает свои настройки.

Существующие MCP-инструменты сохраняют прежнюю семантику:
`vpn_switch_profile` заменяет **все** активные подключения одним профилем;
`vpn_disconnect` отключает **все**. Для одновременного подключения используется UI.

## Проверки сборки

`go test ./...` проверяет независимые процессы, переключение обратно в одиночный
режим, восстановление процесса, API и маршрутизацию на поддельных сетевых cmdlet.
Тесты не подключают реальные VPN и не меняют маршруты Windows. Дополнительно
выполняются `go vet ./...` и Windows-сборка. Реальная совместимость трёх рабочих
серверов должна быть проверена отдельно после запуска этой версии.

Сборка в отдельный каталог без замены установленного EXE:

```powershell
.\scripts\build-windows.ps1 -OutputDirectory .\dist\multi-preview
```
