# VPN для агентов

`openconnect-vpn` — локальный MCP-сервер по stdio. Он управляет тем же процессом VPN, что и окно OpenConnect Multi. Отдельный агент не создаёт отдельное хранилище и не получает пароли.

## Установка в Codex

```powershell
.\scripts\build-windows.ps1
.\scripts\install-mcp.ps1
```

Перезапустите старую версию OpenConnect Multi и обновите подключение MCP в клиенте (при необходимости перезапустите Codex). Затем: «Переключи VPN на Office». Подсказки встроены в `initialize.instructions` и описания инструментов; `AGENTS.md` помогает агентам в этом проекте. Скрипт установки также добавляет один помеченный блок `openconnect-vpn` в пользовательский `$CODEX_HOME/AGENTS.md` (или `~/.codex/AGENTS.md`), сохраняя существующие инструкции. Это подсвечивает VPN-инструменты и в других проектах.

Удаление: `codex mcp remove openconnect-vpn`, затем удалите только блок между `<!-- openconnect-vpn -->` и `<!-- /openconnect-vpn -->` из пользовательского AGENTS.md.

Для другого хранилища: `scripts/install-mcp.ps1 -ConfigDir C:\path\to\vault`. То же значение должно использовать приложение с `--config-dir`.

## Другие MCP-клиенты

Используйте абсолютные пути:

```json
{
  "mcpServers": {
    "openconnect-vpn": {
      "command": "C:\\path\\to\\OpenConnectMulti\\dist\\openconnectmulti-mcp.exe",
      "args": ["--config-dir", "C:\\Users\\USER\\AppData\\Roaming\\OpenConnectMulti"]
    }
  }
}
```

MCP-бинарник работает без прав администратора и без зависимостей Node/Python. Рядом должен лежать `openconnectmulti.exe`; можно указать другой путь через `--app`. Приложению Windows по-прежнему может потребоваться подтверждение UAC для VPN. MCP не обходит UAC.

## Инструменты

| Инструмент | Назначение |
|---|---|
| `vpn_status` | Доступность приложения, блокировка, состояние VPN, следующая операция |
| `vpn_open_app` | Запустить приложение; если оно работает, открыть его интерфейс в браузере |
| `vpn_list_profiles` | ID, имя, сервер и протокол профилей — без учётных данных |
| `vpn_switch_profile` | `{"profile":"точный ID или уникальное имя"}`; переключить VPN |
| `vpn_disconnect` | Отключить VPN |

Имена сравниваются без учёта регистра. При совпадающих именах нужен ID. Неизвестный профиль не отключает текущее соединение. Повторный выбор текущего подключающегося/работающего профиля ничего не перезапускает. Изменения подключения видны в панели «MCP · Управление агентами».

## Доступ и ограничения

- Сначала пользователь разблокирует приложение своим PIN в окне. MCP не принимает PIN, не создаёт профили и не читает пароли, логи или дополнительные аргументы.
- После блокировки список профилей и изменение подключения недоступны. Уже запущенное соединение продолжает работать.
- Приложение публикует фактический локальный адрес и случайный токен сессии в `agent-endpoint.json` рядом с vault. MCP перечитывает файл при каждом вызове, поэтому смена порта после перезапуска не требует перенастройки.
- Токен хранится локально, не в MCP-конфигурации. Не публикуйте каталог хранилища. Доступ рассчитан на доверенные процессы той же учётной записи; это не изоляция от вредоносных программ этого пользователя.
- Мост принимает только loopback-запросы с токеном и без браузерного Origin. Прокси и HTTP-переадресации отключены. При запуске приложения не на `127.0.0.1` обнаружение MCP не публикуется.
- `connected` в текущем VPN-движке означает работающий процесс OpenConnect, а не проверенную доступность сети через туннель. Агент получает эту оговорку в каждом статусе.
- Переключение VPN может прервать интернет-соединение самого агента; команды подключения не повторяются автоматически.

## Проверки и протокол

Транспорт — [MCP stdio](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports), JSON-RPC 2.0, версии 2024-11-05 / 2025-03-26 / 2025-06-18. Поддерживаются initialize, ping, tools/list, tools/call; stdout содержит только протокол. Регистрация через [Codex MCP CLI](https://developers.openai.com/learn/docs-mcp).

`go test ./...` проверяет протокол, авторизацию, блокировку, выбор профилей и обмен с локальным приложением на временном хранилище. Тесты не подключаются к настоящим VPN.
